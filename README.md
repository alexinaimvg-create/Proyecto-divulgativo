# Archivo de divulgacion cientifica: Optica y fisica moderna

Proyecto de clase para construir un archivo de divulgacion cientifica sobre temas de optica y fisica moderna. La idea principal no es solo presentar experimentos, sino explicar como comunicar estos temas a publicos con distintos niveles de conocimiento.

## Objetivo

Crear un archivo claro, visual y accesible que explique experimentos o demostraciones de optica y fisica moderna para tres tipos de publico:

- Adolescentes
- Jovenes
- Adultos

Cada integrante desarrollara un tema con una demostracion sencilla, una explicacion cientifica breve y una adaptacion del lenguaje para cada publico.

## Estructura del proyecto

- `docs/asignaciones.md`: temas, responsables y notas de enfoque.
- `docs/calendario.md`: fechas escalonadas de entrega.
- `docs/estructura-del-archivo.md`: secciones sugeridas para el archivo final.
- `docs/tablero-de-avance.md`: checklist de seguimiento por persona.
- `plantillas/reporte-individual.md`: formato para que cada integrante entregue su parte.
- `entregas/`: carpeta para guardar los reportes individuales.

## Regla comun para todos los reportes

Cada integrante debe incluir:

1. Tema asignado.
2. Objetivo del experimento o demostracion.
3. Materiales.
4. Procedimiento.
5. Explicacion cientifica breve.
6. Explicacion para adolescentes.
7. Explicacion para jovenes.
8. Explicacion para adultos.
9. Aplicacion en la vida diaria.
10. Posibles preguntas del publico.
11. Medidas de seguridad.
